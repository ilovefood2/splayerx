xplayer Support

Import videos and folders

Open Library and tap +, then Import Videos or Import Folder. Choose files from the iOS Files picker. Folder imports preserve nested folders. Imports copy files, so enough free device storage is needed. Keep xplayer open until the copy finishes. Duplicate names receive a numbered suffix.

You can also use Files or Finder file sharing to copy videos into On My iPhone or On My iPad → xplayer → Videos. Pull down in Library to refresh.

Supported videos

xplayer supports MP4, M4V, and MOV containers with codecs supported by your device's Apple media player, typically H.264 and HEVC. A filename extension alone does not guarantee its codec is supported. MKV, AVI, protected/DRM content, and arbitrary desktop codecs are not supported.

Folders and playlists

Use + → New Folder to create a folder. Long-press a file or folder to move it or add its videos to a playlist. Folders can also be renamed. In Playlists, create a list, add videos from any folder, and use Edit to reorder or remove entries. Play All advances to the next video automatically.

Moving files within xplayer updates playlists. If you move or rename a file outside the app, remove its missing playlist entry and add the file again. Removing a playlist entry does not delete the video.

Playback

Tap a video to play it. Tap the video area to show Apple's playback controls. Use Previous and Next for the playback queue. Done stops playback. Backgrounding the app pauses playback. If audio plays on another device, check the system audio output or any device-mirroring session on your Mac.

Report a problem

Email a@ikel.ca or open https://github.com/ilovefood2/xplayer/issues and describe the problem, your device model, iOS version, app version, and steps to reproduce it. For playback issues, include the container and codec if known. Do not attach private videos or personal information to a public issue. The application does not send logs or media automatically.
