# iOS icon

`SPlayer/Assets.xcassets/AppIcon.appiconset/AppIcon.png` was generated for this
iOS application on 2026-10-18 using the built-in ImageGen tool. It replaces the
icon previously copied from the upstream SPlayer project. No upstream artwork
or reference image was supplied. The generated artwork was resized to the
1024 × 1024 opaque PNG required by the app icon asset catalog.

Generation prompt:

> Use case: logo-brand. Create a brand-new original iOS video-player app icon, exactly 1024 by 1024 pixels, opaque square full-bleed artwork. Deep midnight navy background, elegant large mint-to-turquoise play triangle inset into a simple overlapping pair of rounded video cards, suggesting an organized video library and playlists. Strong silhouette, premium minimalist geometric design, subtle dimensional highlights, crisp clean edges, generous negative space, easily recognizable at 48 pixels. The icon artwork fills the square; DO NOT bake in rounded exterior corners, no border or outer padding, no device mockup. No text, no letters, no numbers, no orange, no familiar brand logos, no reference to the existing SPlayer logo. One finished app icon only.
